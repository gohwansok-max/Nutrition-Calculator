# 영양성분표시 계산기 (QA+)

등급: A / 상태: 개발 중 (초판)

- 무엇 : 시험성적서 분석치(100g/ml당)를 입력하면 「식품등의 표시기준」 세부표시방법의 반올림 규칙을 자동 적용해 영양성분 표시서식을 생성하는 계산기 (PWA — 홈 화면 설치, 오프라인 계산 지원)
- 누가 씀 : QA+ 채널 회원(외부 배포) — GitHub Pages로 공개
- 스택 : 단일 HTML(오프라인 계산 로직, Pretendard 웹폰트만 CDN 사용) + manifest.json + sw.js(서비스워커) — 별도 서버·DB 없음
- 데이터 : 저장하지 않음(세션 내 계산만, 새로고침 시 초기화) — 데이터 백업 대상 아님
- 배포 : GitHub Pages (레포 루트에 `index.html`·`manifest.json`·`sw.js`·`icons/` 폴더를 그대로 배치)

## PWA 배포 시 확인할 것
- 반드시 **레포 루트**(또는 서브폴더 전체를 그대로) 배치 — `manifest.json`·`sw.js`·아이콘 참조가 모두 상대경로(`./`)라서 폴더 구조가 깨지면 설치 배지가 안 뜹니다.
- HTTPS 필수 — GitHub Pages는 기본 HTTPS라 별도 조치 불필요.
- 아이콘/설명 문구를 바꾸려면 `manifest.json`과 `icons/` 폴더를 함께 교체하세요.
- 캐시된 앱을 업데이트하려면 `sw.js`의 `CACHE_VERSION` 값을 올려야 사용자 브라우저의 이전 캐시가 갱신됩니다(예: v1 → v2). 이 파일을 고치지 않고 index.html만 바꾸면 이미 설치한 사용자에게는 옛 버전이 계속 보일 수 있습니다.

## 계산 근거
- 반올림 단위: 열량 5kcal / 나트륨 5·10mg / 탄수화물·당류·단백질 1g / 지방·포화지방 0.1·1g / 트랜스지방 0.1·1g / 콜레스테롤 5mg
- [표3] 1일 영양성분 기준치: 나트륨2000mg, 탄수화물324g, 당류100g, 단백질55g, 지방54g, 포화지방15g, 콜레스테롤300mg
- 열량 자동계산식: 탄수화물4 + 지방9 + 단백질4 (kcal/g) — 당알콜·식이섬유 별도 열량계수 미반영(향후 보완 필요)
- 내용량 작성방법(품목제조보고서 영양성분분석표 가이드 ①②③) 반영: ①총 내용량당 — 표시기준량=총내용량 / ②100(g·mL)당 — 표시기준량=100(고정), 헤더에 총내용량 별도 병기 / ③단위 내용량당 — 표시기준량=단위내용량, 헤더에 총내용량+단위내용량 모두 표기
