영양성분표시 계산기

성적서 분석치 입력 → 식품등의 표시기준 반올림 규칙 자동 적용 → 표시서식 즉시 생성

📅 소비기한 계산기
사용 전 확인. 본 계산기는 「식품등의 표시기준」 별지 영양성분별 세부표시방법 및 [표3] 1일 영양성분 기준치를 근거로 반올림·환산을 자동화한 보조 도구입니다. 법정 표시 의무사항(알레르기, 고열량저영양 표시 등)의 최종 적용 여부와 표시값은 반드시 담당자가 검토 후 확정하시기 바랍니다.

1성적서 분석치 입력

시험성적서에 기재된 값을 기준량 100g(또는 100ml)당 수치로 입력하세요.
💡 제로/저당 대체감미료 및 식이섬유 열량 자동 보정 (클릭)
「식품등의 표시기준」 고시 열량 계수: 알룰로오스·에리스리톨 0 kcal/g, 타가토스 1.5 kcal/g, 기타 당알코올(말티톨·자일리톨 등) 2.4 kcal/g, 식이섬유 2 kcal/g.
* 탄수화물 중 해당 성분 함량을 아래에 입력하시면 법정 감면 열량을 정밀 계산하여 '열량 직접 입력'에 자동 반영합니다.

2표시 단위 (라벨에 낼 용량)

총내용량, 1회 제공량, 낱개 포장량 등 라벨에 실제로 표시할 용량을 원하는 만큼 추가하세요.
고열량·저영양식품 자동 판정 (선택, 어린이 기호식품 대상)
1회 섭취참고량이 30g 미만인 캔디류·초콜릿류·팝콘 등은 고시에 따라 30g으로 환산 적용해야 하나, 본 계산기는 위에서 선택한 표시 단위의 실제 값으로 판정합니다. 최종 적용은 담당자가 확인하세요.
🥜 알레르기 유발물질 22종 감지 & 혼유 주의문구 생성기 (클릭)
원재료 텍스트를 입력하시거나 체크하시면, 표시사항용 함유 문구와 제조시설 혼유 주의문구를 법정 고시 기준에 맞추어 즉시 자동 생성합니다.
또는 22종 직접 체크:
1) 알레르기 함유 표시 문구
2) 제조시설 혼유 주의문구 (미함유 물질 기준 자동 산출)
QA+ 영양성분표시 계산기 · 오프라인 단일 HTML 도구 · 계산 근거: 식품등의 표시기준(식약처 고시) 영양성분별 세부표시방법 · [표3] 1일 영양성분 기준치
본 도구의 산출 결과는 참고용이며, 법적 책임은 표시 확정권자에게 있습니다.

앱으로 설치하여 사용하기
⚠️ 인앱 브라우저(카카오톡/네이버 등)에서는 앱 설치가 제한됩니다.
화면 우측 하단 또는 상단의 메뉴(··· 또는 더보기)를 누른 후 'Safari로 열기' 또는 '기본 브라우저로 열기'를 선택해 주세요.

아이폰 Safari 브라우저에서 3초 만에 홈 화면에 앱으로 추가할 수 있습니다:

1
Safari 하단 바의 공유 버튼을 터치합니다.
2
메뉴를 아래로 스크롤하여 '홈 화면에 추가'를 선택합니다.
3
우측 상단의 '추가'를 누르면 홈 화면에 영양계산기 앱 아이콘이 생성됩니다!

브라우저 메뉴에서 바로 홈 화면 앱으로 설치할 수 있습니다:

1
브라우저 우측 상단 또는 하단의 더보기 메뉴(⋮ 또는 ≡)를 터치합니다.
2
'앱 설치' 또는 '현재 페이지 추가' → '홈 화면'을 선택합니다.
